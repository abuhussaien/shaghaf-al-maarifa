# شغف المعرفة

مرجع تفاعلي للدراسات الإسلامية للصف السادس، الجزء الأول من المقرر، طبعة 1447هـ / 2025م. يعتمد على الكتاب الذي أرفقه صاحب المشروع، ويحافظ على اسم الموقع وبيانات إعداده.

## المحتوى والتعلم

- جميع الدروس الـ32: التوحيد 9، الحديث والسيرة 14، الفقه 9، موزعة على 13 وحدة.
- لكل درس: سؤال انطلاق، ثلاثة أهداف، شرح منظم مع إحالات إلى صفحات المصدر، ومهمتا تفكير وتطبيق بإرشادات للمراجعة الذاتية.
- 640 سؤالًا مؤلفًا مع الإجابات والتغذية الراجعة: 320 اختيارًا من متعدد و320 عبارة لفحص الصحة.
- اختبار الدرس: 10 أسئلة متنوعة تُختار عشوائيًا من بنك العشرين؛ واختبار الوحدة: 20 سؤالًا تغطي دروسها.
- 64 لعبة: لكل درس عشرة أزواج في «جسور المعرفة»، وعشر بطاقات في «ميزان الفهم». تستخدم بطاقات الميزان عبارات بنك الأسئلة نفسه؛ ولا تُحسب أسئلة جديدة إضافية.
- جميع صفحات الملف الأصلي الـ136 متاحة بصريًا، مع عشرة ملفات PDF تشمل الصفحات كلها دون حذف. قُسمت ملفات PDF لتسهيل التنزيل، مع المحافظة على صفحات المصدر.
- الشرح صياغة تعليمية؛ والنصوص والأدلة والرسوم والتقويم الأصلي متاحة في تبويب الكتاب. لا يُستخدم النص المستخرج آليًا من PDF مصدرًا معروضًا للآيات أو الأحاديث.

## التقدم والتقارير

التقدم محفوظ محليًا على جهاز الطالب، دون حساب أو خدمة جمع بيانات. يمكن تصدير نسخة احتياطية واستعادتها. لا تستعاد جلسة اختبار غير مكتملة، لكن إجاباتها تحفظ للمراجعة. يُسجل مجموع الاختبار عند إكماله.

الإتقان يعني 80٪ فأكثر في اختبار الدرس. القراءة والألعاب والإتقان مؤشرات مستقلة. النقاط تمنح مرة واحدة للإجابة الصحيحة، مع مكافأة واحدة لتصحيح خطأ سابق، ولمستوى الإتقان، ولإكمال اللعبة. الأصوات نغمات قصيرة ينشئها المتصفح بعد تفعيل المستخدم لها؛ والوضع الصامت هو الافتراضي.

تقارير المعلم تأتي من ملفات يصدرها الطلاب ويستوردها المعلم بنفسه. ليست هناك مزامنة أو أرقام افتراضية أو درجات رسمية. تحتوي التقارير على عدد التأملات دون نصوصها. عند تكرار هوية الطالب يحتفظ الموقع بالتقرير الأحدث.

## تعديل المحتوى والتحقق

الموقع HTML/CSS/JavaScript دون اعتماد على إطار عمل أو خادم تطبيقات. ملفات المحتوى المؤلفة موجودة في `scripts/curriculum/`. لتوليد المحتوى وتشغيل الاختبارات وتجهيز ملفات النشر:

```bash
python scripts/generate_content.py
node --test tests/engine.test.cjs
node --check app.js
python scripts/build.py
```

يُنتج التوليد `content/curriculum.js`. يراجع عدد الدروس والأسئلة والأزواج والبطاقات، وفرادة الخيارات، ووجود صفحات المصدر. تختبر الاختبارات خلط الإجابات، وتغطية الوحدات، ومنع تكرار المكافآت، وشرط الإتقان، وتنقية النسخ والتقارير المستوردة. لا تعد هذه الفحوص مراجعة شرعية مستقلة أو اختبار متصفح بصريًا.

ملفات النشر في `dist/`. يمكن نشر محتوياتها في جذر مستودع GitHub Pages أو مسار الموقع؛ فجميع الأصول تستخدم مسارات نسبية. إعداد استضافة نسخة المراجعة في `.openai/hosting.json`.

## المصدر والخطوط

المصدر: وزارة التعليم، كتاب الدراسات الإسلامية للصف السادس، الجزء الأول من المقرر، طبعة 1447هـ، الملف الذي أرفقه صاحب المشروع. يُرجع إلى الطبعة نفسها عند تعديل تعريف أو حكم أو نص، مع الحفاظ على قيود الأحكام كما وردت في المقرر.

الخطوط Noto Sans Arabic وNoto Kufi Arabic، ونسخ ترخيص SIL Open Font License محفوظة بجانبها في `assets/fonts/`.
